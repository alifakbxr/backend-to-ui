# Changelog

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) in a lightweight form and intends to use [Semantic Versioning](https://semver.org/).

## [Unreleased]

### v1.5.0 — lean and evidence-first execution
- Cut the core skill's prompt footprint and load task-specific references progressively, preserving hard quality gates.
- Make optional subagent/swarm execution user-opt-in only, with explicit token-cost tradeoffs, isolated work ownership and one integration owner.
- Add live browser/DevTools/Playwright/browser-agent protocol for real interactions, console/network checks, responsive screenshots and truthful unavailable-tool fallback.
- Distinguish approved, observed and provisional design sources; avoid mandatory contract files and two-composition work for trivial fixes.
- Fix AGY-specific installation documentation and include `antigravity-cli` in CI install matrix.
- Add regression checks for opt-in, lean workflow, actual browser evidence and contract status.


### v1.4.0 — portable design authority
- Introduce a versioned project `UI_CONTRACT.json` with a contract policy, example, and validation script; model/host aesthetic defaults carry no authority.
- Require explicit provenance for design decisions and reject inference-backed `approved` contracts.
- Add Antigravity/Gemini/Codex on-disk diagnostic with duplicate/stale copy detection and honest activation limitations.
- Extend tests and CI with contract provenance and host-discovery regression checks.
- Add a cross-agent evidence comparer that rejects mismatched project/skill/contract/prompt fingerprints and reports unverified claims explicitly.
- Preserve existing-frontend workflows, mandatory stack selection, and zero promotional videos/GIFs.


### Removed
- Removed the introductory GIF and promotional media references; the repository now focuses on the Agent Skill and its documentation.

### Repository
- Renamed distribution repository to `product-ui` while keeping the Agent Skill name `backend-to-ui`.
- Consolidated installation, publishing, release and design reference documentation into the root README and existing skill references; removed `docs/`.

### Skill
- Added explicit support for improving frontend-only and established frontend projects in any framework.
- Requires preservation of working components, routing, styling conventions and state before redesign.
- Extended behavioral scenarios for React, Angular, Svelte, WordPress and frontend-only read-only audits.
- Retained the mandatory stack-choice gate and performance/visual stop-ship rules.



### Added
- Mandatory frontend-stack choice gate: ask when unspecified; no silent native HTML fallback.
- Portable behavioral evaluation scenarios, evidence format and offline evaluation runner.
- Performance/visual acceptance scenarios with honest reporting of unexecuted agent runs.
- Release checklist and version-consistent documentation.

### Changed
- Clarified that one-shot begins after frontend stack choice is resolved.
- Extended CI with evaluator unit tests and scenario coverage checks.
